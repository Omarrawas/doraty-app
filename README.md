## 🌟 نظرة عامة
**تعليمي** ليس مجرد تطبيق، بل هو نظام بيئي متكامل للتعليم الإلكتروني يهدف إلى أتمتة العملية التعليمية بالكامل. من تسجيل الطلاب، إدارة الدورات، إنشاء الاختبارات المتقدمة، وصولاً إلى إصدار الشهادات والتقارير المالية. تم تصميمه بعناية ليكون قابلاً للتوسع (Scalable) وسهل الاستخدام (User-Friendly).

## 💎 الميزات الرئيسية (Key Features)

### 👨‍🎓 للطلاب (تجربة تعلم غامرة)
*   **📚 إدارة الدورات الذكية:** تصفح الدورات، تتبع التقدم التلقائي، واستئناف الدروس من حيث توقفت.
*   **📝 نظام اختبارات متقدم:** اختبارات مع مؤقت زمني، أنواع أسئلة متعددة (اختيار، صح/خطأ، مقالي)، وتصحيح فوري.
*   **📥 وضع عدم الاتصال (Offline Mode):** تحميل الدروس والمحتوى لمشاهدتها بدون إنترنت (مشفرة ومحمية).
*   **💬 تفاعل مباشر:** طرح الأسئلة، المشاركة في المناقشات، وتقييم الدروس.
*   **🏆 نظام التحفيز (Gamification):** شارات، نقاط، وشهادات عند إتمام الدورات.

### 👨‍🏫 للمعلمين (أدوات قوية للإبداع)
*   **📊 لوحة تحكم المدرس:** إحصائيات شاملة عن أداء الطلاب، مبيعات الكورسات، والتقييمات.
*   **✍️ منشئ اختبارات متطور:** بنك أسئلة، استيراد/تصدير، ووسائط متعددة في الأسئلة.
*   **👥 إدارة الطلاب:** متابعة تقدم كل طالب، تصحيح الإجابات المقالية، وإرسال ملاحظات خاصة.
*   **📢 التواصل الفعال:** إرسال إشعارات وتحديثات للطلاب المسجلين.

### 🎛️ للإدارة (تحكم كامل)
*   **🛡️ نظام صلاحيات دقيق (RBAC):** إدارة كاملة للأدوار (طالب، مدرس، أدمن، سوبر أدمن).
*   **💰 إدارة مالية متكاملة:** متابعة الطلبات، التحقق من إيصالات الدفع، وإصدار التقارير المالية.
*   **📈 تقارير وتحليلات:** لوحات معلومات تفاعلية توفر رؤى عميقة حول أداء المنصة.
*   **🔔 نظام إشعارات مركزي:** إدارة الإعلانات والتنبيهات لجميع المستخدمين.

## 🛠️ البنية التقنية (Technical Architecture)

### 📱 Frontend (تطبيق الهاتف)
*   **Framework:** Flutter (Cross-platform for iOS & Android).
*   **State Management:** Provider / Riverpod (لأداء عالي وإدارة حالة سلسة).
*   **Video Player:** مشغل فيديو مخصص مع ميزات الحماية والتحكم بالسرعة والجودة.
*   **Secure Storage:** تخزين آمن للبيانات الحساسة والرموز (Tokens).
*   **Localization:** دعم كامل للغتين العربية والإنجليزية.

### ☁️ Backend (البنية التحتية)
*   **Database:** PostgreSQL (عبر Supabase) - قاعدة بيانات علائقية قوية.
*   **Authentication:** Supabase Auth (Email, Phone, Google, Apple).
*   **Storage:** تخزين سحابي آمن للملفات والوسائط مع سياسات وصول دقيقة.
*   **Edge Functions:** دوال سحابية لمعالجة العمليات المعقدة (الدفع، الإشعارات) بأمان وسرعة.
*   **Security:** Row Level Security (RLS) لضمان أن كل مستخدم يصل فقط لبياناته المصرح بها.

## 📲 شاشات التطبيق (Screenshots & Modules)

### وحدة التعلم والمحتوى
*   **Home:** واجهة رئيسية ديناميكية تعرض الدورات المميزة، آخر المشاهدات، والتوصيات.
*   **Course Player:** مشغل دروس يدعم الفيديو، النصوص، والاختبارات القصيرة.
*   **My Learning:** مكتبة الطالب الشخصية مع فلاتر للوصول السريع.

### وحدة الاختبارات والتقييم
*   **Exams List:** قائمة بالاختبارات المتاحة، القادمة، والمنجزة.
*   **Exam Room:** بيئة اختبار آمنة مع مانع للغش ومؤقت زمني.
*   **Results:** تقارير نتائج فورية وتفصيلية مع مراجعة الإجابات.

### وحدة الإدارة والمالية
*   **Admin Dashboard:** مركز القيادة لإدارة المستخدمين، المحتوى، والمالية.
*   **Financial Reports:** تقارير مفصلة للمبيعات والاشتراكات.
*   **Verification:** شاشات خاصة لمراجعة إيصالات الدفع اليدوية وقبولها.

## 🚀 جاهزية الإطلاق (Why Buy?)

1.  **كود نظيف ومرتب:** (Clean Architecture) يسهل التعديل والتطوير المستقبلي.
2.  **أداء عالي:** تحسينات في استهلاك الذاكرة وسرعة تحميل البيانات.
3.  **حماية المحتوى:** آليات لمنع تسجيل الشاشة وحماية حقوق الملكية الفكرية.
4.  **قابلية التخصيص:** نظام ثيمات (Theming) لتغيير الألوان والهوية البصرية بسهولة.
5.  **دعم فني:** وثائق كاملة (Documentation) وملفات إرشادية لكل جزء من النظام.
