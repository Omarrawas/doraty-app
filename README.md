# مشروع دوراتي (Doraty) 🎓

**دوراتي** هي منصة تعليمية متكاملة مصممة خصيصاً لخدمة جميع الطلاب في سوريا وتوفير بيئة تعليمية تفاعلية وحديثة. يهدف المشروع إلى ربط الطلاب بالمدرسين وتقديم الدروس، الدورات، والامتحانات بأفضل صورة ممكنة مع التركيز على الأمان وتجربة المستخدم.

---

## 🌟 أهم الميزات (Features)

تتضمن المنصة مجموعة واسعة من الميزات المصممة لتلبية احتياجات الطلاب والمدرسين والإدارة:

### 1- إدارة الحسابات والأدوار 👥
* **تسجيل الدخول والتسجيل:** دعم تسجيل الدخول باستخدام البريد الإلكتروني، و Google Sign-In.
* **الأدوار المتعددة:** واجهات وصلاحيات مخصصة لكل من (الطالب، المدرس، مسؤول النظام/الأدمن).
* **إدارة الملف الشخصي:** إمكانية تعديل البيانات الشخصية ومتابعة النشاط.

### 2- الدورات والدروس 📚
* **مشغل فيديو مدمج:** دعم تشغيل الفيديوهات المرفوعة بالإضافة إلى دعم تشغيل فيديوهات (YouTube) بشكل مباشر.
* **عارض ملفات PDF:** عرض الملازم والمقررات بصيغة PDF داخل التطبيق بسلاسة تامة.
* **محرر نصوص متقدم:** استخدام `Flutter Quill` لكتابة وعرض محتوى الدروس بدعم كامل للنصوص المنسقة (Rich Text Editor).
* **دعم المعادلات الرياضية (LaTeX):** عرض المعادلات والقوانين الرياضية بشكل صحيح واحترافي.

### 3- الامتحانات والملاحظات 📝
* **نظام امتحانات متكامل:** تقديم اختبارات للطلاب وتقييم نتائجهم.
* **الملاحظات الخاصة:** إمكانية حفظ الطلاب للملاحظات المتعلقة بكل كورس للعودة إليها.

### 4- التحميل المسبق ووضع دون اتصال (Offline Mode) 📥
* إمكانية تحميل الفيديوهات والمقررات لمشاهدتها لاحقاً بدون الحاجة لاتصال بالإنترنت (تدعم التخزين المحلي).

### 5- الاشتراكات والدفع 💳
* **تفعيل الاشتراكات عبر رموز QR:** توفير نظام ماسح ضوئي لرموز الاستجابة السريعة (QR Code Scanner) لتسهيل عمليات التفعيل والدفع والشحن سواء للكورسات أو المحافظ الرقمية.
* إعدادات دفع مرنة متصلة بلوحة التحكم.

### 6- حماية المحتوى والخصوصية 🔒
* **منع التقاط الشاشة أو تسجيلها:** حماية الكورسات والمحتوى المدفوع من السرقة من خلال تعطيل التقاط وتسجيل الشاشة (Screen Security).
* تشفير البيانات الحساسة المخزنة محلياً.

### 7- الإشعارات والتقييمات 🔔
* **إشعارات فورية (Push Notifications):** إرسال إشعارات للطلاب عند توفر دروس جديدة أو إعلانات هامة باستخدام Firebase Cloud Messaging.
* **نظام مراجعة وتقييم:** تقييم الكورسات والمدرسين من قبل الطلاب.

## 📱 المنصات المدعومة (Supported Platforms)

المشروع مصمم ليكون متعدد المنصات (Cross-Platform) ويعمل بكفاءة عالية على:

* **نظام الأندرويد (Android):** متوفر بصيغة `APK` مقسم للمعماريات المختلفة وصيغة `AAB` للرفع على متجر جوجل بلاي.
* **نظام الويندوز (Windows Desktop):** نسخة سطح مكتب مخصصة للعمل بشكل مستقل، تدعم الحزم بصيغة `.zip` وكذلك الـ `MSIX`.
* *قابل للتوسعة مستقبلاً لدعم الويب (Web) و (iOS).*

## 🛠 التكنولوجيا والتقنيات المستخدمة (Tech Stack)

* **إطار العمل:** Flutter / Dart
* **إدارة الحالة (State Management):** Provider
* **قاعدة البيانات والواجهة الخلفية (Backend & DB):** Supabase (للمصادقة، التخزين، وقواعد البيانات)
* **التخزين المحلي (Local Storage):** Hive & Shared Preferences & Flutter Secure Storage
* **تحليل النصوص والوسائط:**
  * مشغلات الفيديو: `video_player`، `chewie`، `youtube_player_flutter`
  * عارضات الـ PDF: `flutter_pdfview`، `syncfusion_flutter_pdfviewer`
  * محرر النصوص والرياضيات: `flutter_quill`، `flutter_tex`
  * واجهات تفاعلية: `shimmer`، `flip_card`، `curved_navigation_bar`

## ⚙️ أتمتة النشر (CI/CD)

يستخدم المشروع **GitHub Actions** في عمليات البناء والاختبار والنشر المستمر (CI/CD Flow):
* **بناء الأندرويد:** بناء تلقائي لنسخ التحديث من (Split APKs) و (AppBundle/AAB)، بالإضافة للتعامل الآمن مع (Keystore) للـ Signing.
* **بناء الويندوز:** بناء نسخة ويندوز مضغوطة جاهزة للعمل.
* **إصدارات GitHub:** إنشاء (Release) بشكل تلقائي مدمج مع (Changelog) يوضح التحديثات الأخيرة.
* **إشعارات تيليجرام (Telegram Bot):** إرسال رسائل آلية لروبوت تيليجرام عند اكتمال أي بناء مع إرفاق روابط التحميل المباشرة لنسخ الأندرويد والويندوز.
